## Agent 的确定性边界

LoRA 只负责把自然语言需求转换为结构化查询计划，不直接修改笔记。运行时仍通过以下工程约束保证确定性：

1. 使用 JSON Schema 校验查询计划，拒绝缺字段、类型错误和越界参数。
2. 工具调用采用显式白名单，仅开放检索、读取元数据和生成 Obsidian 定位链接等只读能力。
3. 执行层不信任模型生成的路径和参数，统一做规范化、范围限制与安全检查。
4. 解析失败、工具不存在或证据不足时返回安全回退，不猜测执行结果。
