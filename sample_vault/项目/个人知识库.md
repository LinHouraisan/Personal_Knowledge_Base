# 个人知识库

目标是让长期积累的 Markdown 笔记可以被自然语言检索，同时保留 Obsidian 原有的文件结构和编辑体验。服务不接管写入，只返回建议和原笔记位置。

## 方案组成

扫描流程见 [[RAG检索流程]]，向量模型选择见 [[Embedding选择]]，Agent 边界见 [[LangChain工具调用]]。API 使用 [[FastAPI服务化]]，回答可信度依赖 [[模型幻觉约束]]。

## 设计判断

第一版使用 JSON 保存可再生成索引，但查询阶段全部在内存完成。数据量增加后按 [[向量索引迁移]] 替换底层存储。
