# 个人知识库使用说明

这是一个可直接演示的个人知识库。用它找资料、回顾学习和项目、确定下一步。全部 25 篇样例都是公开虚构内容，没有读取你的私人笔记。

## 打开界面

在项目文件夹双击 **启动演示.cmd**，浏览器会打开 [个人知识库](http://127.0.0.1:8011/)。重复打开会使用已经启动的演示。当前电脑的运行环境已保留。

## 三分钟演示

1. **查资料**：输入“RAG”，查看搜索结果，再点“查看原文”核对出处。
2. **做复盘**：点右侧“这周学了什么”。能看到已完成的事、仍没解决的事以及记录中明确写下的下一步。较新的完成记录会覆盖同一件事较早的待办状态。
3. **定下一步**：点“下周先做哪件事”，选择一个已有目标。行动会显示为什么要做、完成标准和来源。
4. **反馈复查**：点“需要改进”，写一句说明并保存。打开“改进记录”，切换“聚焦未完成”后复查，可以对照前后结果。是否解决问题由你核对后确认。

反馈保存在当前浏览器中，刷新页面仍保留，也能导出。清除浏览器数据或更换浏览器不会自动同步记录，重要内容先导出。

## 这版能说明什么

可以展示资料查找、原文核对、学习复盘、项目复盘和反馈改进的完整过程。默认演示按笔记明确记录整理，不调用 AI 模型、不消耗模型额度。原有模型问答和 AI 训练代码仍在，训练成果也已保留。

复盘演示识别的是样例中的日期、主题和明确状态，暂时不能把任意随手笔记自动理解成可靠复盘。没有日期的记录会提示排除，没找到资料时不会补写结论。

## 换电脑或启动失败

缺少运行环境时，在项目根目录安装已有依赖：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[test]"
```

再次双击启动。若提示默认端口被占用，可在项目根目录运行：

```powershell
.\.venv\Scripts\python.exe -B -m app.launch --port 8012
```

其他启动错误可查 `data/demo.log`。文档中的模型密钥配置只用于主动启用真实模型的方式，当前演示不需要填写。
