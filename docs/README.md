# 个人知识库使用说明

用自己的知识积累找答案、做复盘、定下一步。当前项目提供 85 篇公开虚构笔记、7 个明确目标，没有读取你的私人笔记。

## 打开并连接 AI

1. 双击项目根目录的 **启动演示.cmd**，或打开 [个人知识库](http://127.0.0.1:8011/)。
2. 点右上角 **连接 DeepSeek**，在本机页面填写 API Key，点 **保存并检查连接**。不要把密钥发到聊天里。
3. 检查成功后切到 DeepSeek AI；之后可以问答、解读单篇、做复盘和定下一步。未填密钥时仍能离线查资料。

密钥保存在本机项目的 `.env` 文件，已被 Git 忽略；页面不会返回密钥，也不会放进浏览器存储。保存时会发送一条简短的连接测试消息。后续只有你主动发起 AI 操作才会发送相关笔记并使用 DeepSeek API 额度。

默认模型为 DeepSeek Flash，也可在窗口选择 V4 Pro。配置依据 [DeepSeek 官方接口说明](https://api-docs.deepseek.com/)。没有自动上传整个目录或修改原笔记。

## 三种实际用法

**读这一篇**：浏览笔记，打开《请听众复述才算讲清》，点“让 AI 解读这篇”。问题会自动填好，AI 只读取当前选中的这篇。也能继续改写问题。

**对照一段经历**：进入做复盘，选择“阅读与表达”或“个人网站”主题和日期，再整理。AI 会阅读自然段里的前后变化，区分已经做完、仍在推进和没解决的事。每条结果有原文出处，下一步建议会标注为待你确认。

**围绕目标安排下一步**：进入定下一步，选择“能讲清楚一次日常经历”等目标。只使用同一主题的记录，并给出行动、原因和完成标准。

普通“找资料”不调用 AI。需要暂停模型时，把页面的整理方式切回“离线整理”；刷新资料不会自动重新打开 AI。离线方式只识别明确的状态记录，不能理解全部自然段笔记，会提示哪些记录没有纳入。

## 样例包含什么

原有学习方法和知识库项目记录保留，新增阅读与表达、时间安排、英语学习、个人网站、资料整理五组连续记录。新增部分使用自然段，包含计划未做、问题已解决、后续又出现问题、出处不确定等情况，用于检查 AI 的真实阅读能力。

全部是虚构场景，不能当作真实项目效果或个人经历。已有 AI 训练成果保留，本次没有重新训练。

## 如何核对和改进

答案的引用必须存在于实际发送给模型的原文中，引用检查失败会提示重试，不能把它当作成功答案。引用存在仍不等于结论一定正确，需要你对照原文判断。

可保存反馈，再从“改进记录”对照前后结果。AI 记录在复查时仍需启用 AI；暂停时不会偷偷调用。反馈保存在当前浏览器中，更换浏览器不会自动同步，重要内容可导出备份。内置浏览器的文件下载尚未确认落盘。

为控制单次资料量，问答最多取 8 篇相关笔记；复盘最多读最近 24 篇，每篇最多 4000 字，超过时会提示。可缩小主题和日期继续查看。无匹配资料时不调用模型，不编造结果。

## 换电脑或启动失败

缺少运行环境时，在项目根目录执行下面两行，再双击启动：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[test]"
```

默认端口被其他程序占用时，可运行：

```powershell
.\.venv\Scripts\python.exe -B -m app.launch --port 8012
```

其他启动错误查看 `data/demo.log`。如果只想启动严格不带模型的版本，使用 `.\.venv\Scripts\python.exe -B -m app.demo --port 8012`。
