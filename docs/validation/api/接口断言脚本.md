# 接口断言脚本
在 Apifox 对应接口用例的后置脚本中使用；未在客户端执行。

## API-01 健康检查

请求：GET {{baseUrl}}/health

```javascript
pm.test("HTTP 200",()=>pm.response.to.have.status(200));
pm.test("状态字段存在",()=>pm.expect(pm.response.json()).to.have.property("index_ready"));
```

## API-02 正常检索

请求：GET {{baseUrl}}/v1/search?q=RAG&top_k=3

```javascript
pm.test("HTTP 200",()=>pm.response.to.have.status(200));
pm.test("来源数组存在",()=>pm.expect(pm.response.json().sources).to.be.an("array"));
const sources=pm.response.json().sources; if(sources.length) pm.collectionVariables.set("noteId",sources[0].note_id);
```
